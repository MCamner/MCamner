Checks

These checks stay inside the browser sandbox. They are useful for first-line readiness validation, but not for deep policy inspection. For IGEL UMS, Scout/eLux, or local client settings, this page should later be paired with a management backend or local helper.

What v2 adds

  • External JSON config support for environment name, notes, and endpoint lists.
  • Query-string overrides for environment, client family, and endpoints.
  • Improved client detection with visible confidence level.
  • Downloadable reports as both text and JSON for support or ticket workflows.
  • Optional local helper-agent integration on localhost for host-level signals.
