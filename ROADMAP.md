# MCamner Roadmap

MCamner is a GitHub Pages profile and client-readiness toolkit for endpoint
validation, EUC architecture, and practical operations demos.

## Status

Current phase:

```text
maintenance / profile polish
```

No active release is scheduled. The roadmap is a maintenance backlog for keeping
the public profile credible and turning reusable endpoint-validation patterns
into clearer demos.

## Current Focus

- Keep the public profile clear and credible
- Improve browser-based client readiness diagnostics
- Make helper-assisted endpoint validation easier to demo
- Turn strong operational patterns into reusable case studies

## Backlog

- Add screenshots for the client readiness pages
- Expand `cases/` with concise architecture and operations notes
- Keep sample client data current with v2 diagnostics
- Improve local helper deployment examples for IGEL OS and eLux
- Add more endpoint profiles
- Add richer report export examples
- Add a small visual gallery for GitHub Pages
- Connect the strongest demos to the broader MQ ecosystem docs

## Non-goals

- No customer-specific data
- No credentials or private endpoint details
- No backend dependency for the public Pages site
